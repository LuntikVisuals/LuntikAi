# LuntikAi

**Локальный ИИ-агент для Android** · v0.5

## Что умеет

- Несколько чатов (drawer справа)
- Подсказки-чипы после ответа ИИ
- `/create skill имя | описание` — свои навыки
- Песочница кода (Python / JS / C++)
- Профиль + цвета + жидкое стекло
- TF-IDF + перефраз
- Личности (включая Юморист с предупреждением)
- Сохранение состояния

## Как скачать APK

1. **Actions** → последний успешный **Build APK**
2. Артефакт `luntikai-debug-apk`
3. Установить на телефон

## Команды

- `/create skill шутки | отвечай с лёгким юмором`
- `создай файл hello.py : print("hi")`
- `запусти hello.py`
- `что ты умеешь?`
