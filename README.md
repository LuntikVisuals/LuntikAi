# LuntikAi

**Локальный ИИ-агент для Android**

Учится на твоих текстах, помнит диалог, пишет свои действия, создаёт файлы в чате, умеет личности.

## v0.2 — что умеет

- Просмотр / открытие / редактирование / удаление знаний
- Память и анализ диалога (команда: «анализ диалога»)
- Режим агента: перед ответом пишет список действий
- Файлы внутри чата (создать кнопкой или командой «создай файл …»)
- Личности: Обычный ИИ, Хоррор, Эгоист, Злодей, Добряк, Милый
- Лайк / Дизлайк с комментарием
- Раздумье с вероятностями

## Как скачать APK

1. Зайди во вкладку **Actions**
2. Открой последний успешный **Build APK**
3. Скачай артефакт `luntikai-debug-apk`
4. Установи на телефон

## Команды в чате

- `анализ диалога` — статистика и темы
- `создай файл имя.txt : содержимое` — файл в чате
- привет / как дела — быстрые ответы

## Личности

| Личность | Стиль |
|----------|--------|
| Обычный ИИ | Нейтральный |
| Хоррор | Мрачный, жуткий |
| Эгоист | Самоуверенный |
| Злодей | Хитрый, злорадный |
| Добряк | Добрый, заботливый |
| Милый | Нежный, тёплый |
