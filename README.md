# LuntikAi

**Локальный самообучающийся ИИ для Android**

Учится на твоих текстах, думает с вероятностями, учитывает лайки и дизлайки.

## Возможности (v0.1)

- Добавление текстов / знаний
- Обучение на локальных данных
- Ответы с блоком «Раздумье» и процентами вероятности
- Лайк / Дизлайк + комментарий
- Всё хранится локально на телефоне

## Как скачать APK

1. Зайди во вкладку **Actions**
2. Открой последний успешный запуск **Build APK**
3. Скачай артефакт `luntikai-debug-apk`
4. Установи на телефон (разреши установку из неизвестных источников)
