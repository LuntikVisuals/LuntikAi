# LuntikAi

**Локальный ИИ-агент для Android** · v0.3

## Что умеет

- Знания: добавление, просмотр, редактирование, удаление
- TF‑IDF поиск по знаниям (нормальное «обучение»)
- Память диалога + анализ
- Агент пишет свои действия перед ответом
- Файлы в чате: создать, открыть, **редактировать**, удалить
- Личности: обычный, хоррор, эгоист, злодей, добряк, милый
- **Сохранение** между запусками
- **Экспорт / импорт** данных (JSON)
- **Интернет**: «открой https://…» — скачивает текст страницы
- Лайк / дизлайк с комментарием
- Перефразирование знаний под вопрос
- Дисклеймер: Luntik-ai это ии и он может ошибаться

## Как скачать APK

1. **Actions** → последний **Build APK**
2. Артефакт `luntikai-debug-apk`
3. Установить на телефон

## Команды

- `анализ диалога`
- `создай файл имя.txt : текст`
- `открой https://example.com` — загрузка страницы из интернета

## Как устроено обучение

Не нейросеть, а **RAG**:
1. Тексты режутся и индексируются (TF‑IDF)
2. По вопросу находятся лучшие куски
3. Ответ перефразируется под диалог и личность

Настоящий fine-tune LLM — отдельно, на ПК/сервере.

## Интернет

Агент может открыть URL и прочитать текст страницы.  
Полноценный поиск Google без API-ключа пока не подключён.
